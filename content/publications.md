## Adaptive Global Navigation for Sidewalk Robots

*Integrating OSM Lanelets with Real-Time Pavement Segmentation-Based Correction*

First author · IEEE CoDIT 2026 · pp. 3503–3508

Adapted the Lanelet2 HD-map framework to sidewalks, translating OpenStreetMap
coordinates into local UTM for precise global path planning, with a real-time
vision-based waypoint correction module using depth and semantic segmentation to
prevent pavement-edge drift.
